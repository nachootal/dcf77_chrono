# DCF77_CHRONO
The dcf77_chrono library encodes from a chrono datetime to DCF77 and decodes from a DCF77 bit field to a chrono datetime.

Documentation on how does the DCF77 standard look like is available [here](https://www.trystar.com/wp-content/uploads/document-library/Overview-of-DCF77-Time-Protocol-0012TN0326.pdf)
